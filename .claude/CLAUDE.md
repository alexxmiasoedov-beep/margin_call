# margin_call — памятка для Claude

Бот-сканер маржинального канала MarginData (Telegram) с торговлей на Binance USDT-M и виртуальными журналами стратегий.
Общение с владельцем — по-русски, на «вы».

## Правила

- Репозиторий публичный. Ключи Binance, токен бота, IP и логины сервера — никогда в чат, коммиты, файлы и вывод.
- Личный Telegram-аккаунт владельца к боту и скриптам не подключать. В коммитах — без названий моделей.
- `README.md` — только «# margin_call». Исследования — в `research/sN/`: `ВЫВОДЫ.md` и скрипты.
- Изменения поведения бота (новые правила и журналы, параметры торговли) — только после явного «да» владельца:
  исследование → предложение → согласие. Исправить ошибку, о которой владелец сам просит, — можно.
- Любой push в `main` через ≤ 5 мин уходит на живой сервер с реальной торговлей (TRADE_MODE=live). Перед выкладкой:
  `python3 -m py_compile`, проход `STATE_FILE=<временная папка>/state.json python3 bot/scanner.py --once --dry-run`,
  для новой логики — тест с подменой ответов Binance/Telegram.
- Сеть сервера ненадёжна (медленный DNS, обрывы): при сетевых ошибках — только с паузой, никаких циклов вхолостую;
  лимит Binance (вес 2400 в минуту на IP) общий с другими программами на сервере.

## Устройство

- `bot/scanner.py` — канал, правила, Telegram (команды, рассылка), правила 🇰🇷 🇹🇷 🏦 🆕 📢 ↩️, самописец сервера.
  `bot/trader.py` — исполнитель Binance, виртуальные журналы (`VIRTUALS`, `virt_manage`).
- Выкладка: на сервере `margin-autoupdate.timer` раз в 5 мин запускает `bot/autoupdate.sh`. Он перезапускает бота
  и пишет «🔄 Бот обновлён» только если изменились `bot/scanner.py`, `bot/trader.py`, `bot/autoupdate.sh` или
  `bot/margin-scanner.service`; `research/` и `tools/` бота не трогают. Если быстрая перемотка не удалась, приходят
  только эти четыре файла — код должен переживать отсутствие новых файлов (пример — `bot/margin_known.txt`).
- Сервер: Ubuntu 24.04, рабочий стол через xrdp, служба пользователя `margin-scanner` (`systemctl --user`), папка бота
  `~/projects/margin_call-live/bot`. Состояние — `~/.local/state/margin-call/`: `state.json`, `margin_posts.json`,
  `system.log` (самописец), `margin_rates/`. Ключи и токен — только в `~/.config/margin-call.env`.
  На том же сервере и IP работают другие боты владельца (`spread_monitor.py`, `funding_bot`) — не из этого репозитория.
- Владелец запускает инструменты сам одной строкой
  `curl -sL https://raw.githubusercontent.com/alexxmiasoedov-beep/margin_call/main/tools/<файл> | python3`:
  `export_signals.py` — журналы и журнал службы, `server_health.py` — проверка сервера, `margin_rate_history.py`.
- Исследования и правила журналов: `research/s2` … `research/s12`, в каждой папке `ВЫВОДЫ.md`.
- Данные исследований (свечи 869 фьючерсов за 2 года, премии, фандинг, архив канала MarginData, объявления Binance,
  ставки маржи; ~580 МБ в сжатом виде) — в отдельной ветке `data`, как распаковать — `DATA.md` в ней. Скачивать
  только при надобности: `git clone --branch data --single-branch …`.
