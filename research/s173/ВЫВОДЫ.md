# s173 — изучение: займы, OI, фандинг, потоки денег, лимиты, кластеры; источники разных стран и математика связей

19.11.2026. Этап изучения по правилу чередования после s171–s172 (займы в сочетании с другими показателями — находки нет).
Просьба владельца: изучение по займам, OI, индикаторам, фандингу, движению денег, лимитам и кластерам, источники из разных
стран, глубже в математику и взаимосвязи потоков. Полный отчёт — `reports/изучение.md`. Пробы частот (только число
событий, без доходов) — `study/`.

## Главное

1. **Займы маржи криптобирж наукой не изучены** ни в одной стране (как и в s22). Пороговые сочетания вокруг займа
   исчерпаны (s171, s172). Из литературы по займам осталось два механизма:
   - выбор площадки для шорта (Johnson & So, США) — Г2;
   - сдвиг предложения займа (Chague и др., Бразилия) — пул пишется с 10.11.2026, проверка через 2–3 месяца.
2. **Потоки денег.** Канада, Китай, США: поток без хода цены продолжается, ход цены без потока откатывается. В крипте
   эффект есть, но мал (s23); больше можно получить только многопоточной моделью (Г3).
3. **Стакан.** Перекос мелкого стакана живёт секунды–минуты, через 3 ч знак обратный (Чехия). Глубокий перекос
   на акциях Китая предсказывает неделю с минусом — Г4 (данные `bookDepth` с 01.2023, выгрузка тяжёлая).
4. **«Кластеры» (объём по цене) академически не проверены нигде** — ни 매물대 (Корея), ни 筹码分布 (Китай), ни
   кластерный анализ (Россия), ни 価格帯別出来高 (Япония). Микрооснова надёжна: продают скачком на цене покупки
   (Kaustia, Финляндия), опорная цена по обороту (Grinblatt & Han). Отсюда главная новая гипотеза Г1.
5. **OI и позиции толпы как сигнал момента не работают** (Россия: из 1119 правил по позициям Мосбиржи после поправки
   Бенджамини — Хохберга выжили 10; Индия: OI идёт за ценой; наши s22, s43, s71, s172 — ноль).
6. **Фандинг предсказуем, цена по нему — нет** (Канада, Корея); кэрри к 2025 г. исчезло.
7. **«Рост на споте здоровее»** — утверждение практиков без проверок; по нашим данным для пампов альтов наоборот
   (🛒, s54).
8. **Математика.** Основное — локальные проекции на панели с ошибками Дрисколла — Края; структура связей — PCMCI или
   панельный Гренджер; эндогенность пампов — процессы Хоукса; против перебора — Бенджамини — Хохберг, PBO/CSCV,
   перемешанный контроль. Доли ценообразования, OFI по очередям, VPIN, связность Диболда — Йылмаза описывают рынок,
   но на наших горизонтах сделку не дают.

## Гипотезы по убыванию ценности

Частоты — из проб без доходов (10.2024–10.2026, если не сказано иное).

| № | Гипотеза | В месяц | Проверка |
|---|---|---|---|
| Г1 | «застрявшие покупатели»: возврат снизу в плотную зону покупок 3–30 сут назад → шорт 24–48 ч | перп-профиль 22 / 83 / 103 по трём периодам; спот 115 | дёшево, три периода — `research/s174` |
| Г2 | «выбор площадки»: доля перпа в обороте ×2 к норме при стоящей цене → шорт 7 сут | 26; корзина ~150 | дёшево на 2024–2026 |
| Г3 | временная часть хода по потокам (локальные проекции, VAR Хасбрука) → дневная корзина шорта | ~150 | средне |
| Г4 | перекос глубокого стакана ±1…5% → шорт 3 сут | ~150 | дорого (`bookDepth`) |
| Г5 | след хеджа получателей перед разлоком → двойник 🔑⁺ | 8 | дёшево |
| Г6 | эндогенный памп против внезапного → шорт эндогенных | ~13 | дёшево |
| Г7 | много разных держателей заводят на биржи за 72 ч → двойник 🐋 | 31 | дёшево |
| Г8 | мелкие покупают, крупные продают (aggTrades) → корзина 3 сут | ~150 | дорого |

Записывать вперёд (только по «да» владельца): потолки OI Hyperliquid, ликвидации по WebSocket Binance. Пул займа
Binance уже пишется.

Не подходит (раздел 4 отчёта): OFI и стакан L1, высокочастотное запаздывание бирж, доли ценообразования как сигнал,
прогноз фандинга, OI и позиции толпы, новые пороги вокруг займа, 逆日歩 и календарь закрытия шортов, VPIN как
направление, связность Диболда — Йылмаза, режимы как фильтр, VAR и трансфер-энтропия по каждой монете отдельно.
