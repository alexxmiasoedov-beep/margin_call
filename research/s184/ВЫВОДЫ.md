## Общее

- **Срез** — понедельник 00:00 UTC. Признаки — по данным строго до среза: `feat2_<период>.pkl` s183 (`features.py`,
  `feat_oi.py`). Первые ~30 сут каждого периода без признаков: возраст и окна считаются внутри файла периода, как
  в пробах s183.
- **Вход** — закрытие 15-мин свечи 00:00–00:15 понедельника. Шорт на 7 сут (168 ч), стоп +25%. Комиссия 0,1%,
  фактический фандинг (`s15/common.trade`).
- **Вселенная** — ликвидные альты s183 (`liq5`: оборот перпа ≥ 5 млн $ в сутки за 7 сут, возраст ≥ 30 сут). Без BTC,
  ETH, акций, металлов, стейблкоинов.
- **Статистика:**
  - t — с кластерами по неделе;
  - «вместе» — среднее Δ периодов с весом по числу событий, ошибки периодов независимы;
  - хедж — индекс альтов s103 на фактический срок сделки (в отчёте);
  - плацебо — та же монета за 45 / 90 / 135 сут.

## Г1 — «монета корейской розницы» (главная)

- **Механизм** (Miller; Garfinkel, Hsiao, Hu 2025). На Upbit и Bithumb нет шорта и плеча. Если корейцы — большая часть
  оборота монеты, цену задают оптимисты, а пессимист без монет продать не может. На перпе такое ограничение имеет цену —
  фандинг, а корейское бесплатно: переоценка держится, пока не иссякнет корейский спрос.
- **Признак** — kshare7: оборот Upbit + Bithumb к воне за 7 сут / (Корея + перп + спот Binance за 7 сут).
- **Событие:**
  - kshare7 ≥ 15%;
  - у монеты нет входов 🔝 👀 ⏰ 🇰🇷 🇰🇷🆕 🛒 за 7 сут до среза (s183 `recent_journal`);
  - фандинг за 7 сут f7 > −0,3%.

  Корзина — до 5 монет с наибольшей kshare7.
- **Контроль (а)** — пара для каждой монеты корзины (по убыванию kshare7):
  - монета того же среза с рынком к воне и kshare7 ≤ 3%, с теми же исключениями (журналы, f7);
  - ближайшая по евклидову расстоянию в процентильных рангах оборота qv7 и волатильности vol28 среди ликвидных альтов
    среза; без повторов.
- **Главная статистика** — средняя разность пар «монета корзины − её контроль».
- **Порог:**
  1. Δ > 0 в каждом периоде, вместе t ≥ 3.
  2. Правило владельца для корзины на 2024–2026 гг.: ≥ 20 сделок в месяц, обе половины в плюсе, t ≥ 3, лучше плацебо.
- **Разрезы** (не для отбора):
  - порог 20 / 25%; без вето по фандингу; с журналами (без исключения);
  - контроль (б) — 5 монет с наибольшей долей спота Binance sshare7, те же исключения;
  - доза kshare7: 15–25 / 25–35 / ≥ 35%;
  - премия Кореи kprem7 > 0; «сверх нормы» kabn > 0; Upbit против Bithumb (чья доля больше);
  - 2025 г. отдельно; без трёх самых частых монет; вес 1 / (число недель монеты); с хеджем.

## Г2 — «уход интереса»: падение OI при стоящей цене

- **Механизм** (Hong–Yogo 2012; китайское 减仓). Падение OI при стоящей цене — закрытия с обеих сторон: спекулянты
  уходят, арбитражёры снимают базис, исчезает маржинальный покупатель. Рост OI — продолжение (s175, s22 Г6 — тот же знак).
- **Признаки:**
  - oi_g7 — лог-рост OI в монетах за 7 сут (архив metrics, последняя 5-мин отметка воскресенья, с 12.2021);
  - r7 — лог-ход перпа за 7 сут.
- **Событие** — oi_g7 ≤ ln 0,85 при |r7| ≤ ln 1,1; корзина — до 5 монет с наибольшим падением OI.
- **Контроль той же формы** — oi_g7 ≥ ln 1,15 при |r7| ≤ ln 1,1; до 5 монет с наибольшим ростом OI.
- **Главная статистика** — Δ = среднее «падение» − среднее «рост» (МНК с кластерами по неделе).
- **Порог:**
  1. Δ > 0 в каждом периоде (2020–2022 гг. — только с 12.2021), вместе t ≥ 3.
  2. Правило владельца для корзины «падение» на 2024–2026 гг.
- **Разрезы** (не для отбора):
  - f7 ≥ 0 против < 0;
  - пороги OI −10 / −25%;
  - OI в $ (oi_g7 + r7) вместо монет;
  - второй контроль — 5 случайных монет среза с |r7| ≤ 10% (зерно 184);
  - **Г4 «рост без новых денег» (减仓上涨):** r7 ≥ ln 1,1 и oi_g7 ≤ ln 0,95, корзина по разности процентильных рангов
    r7 − oi_g7, против роста на новых деньгах (oi_g7 ≥ ln 1,05, корзина по сумме рангов);
  - OI / оборот выше и ниже медианы среза; ликвидность ≥ 20 млн $ в сутки; с хеджем.
- Без недель после каскадов (s22 Г6) — не считается: каскады размечены только на 2024–2026 гг.

## Г3 — двойник ⏰ 🔝 👀 🇰🇷 по доле Кореи у монеты

- **Механизм.** Знак двусторонний:
  - Miller: при большой доле Кореи встречного шорта меньше и откат глубже;
  - против: постоянный корейский спрос, откат медленнее.
- **Признак** — kshare7 монеты за 7 полных суток UTC до суток входа по дневной панели s183 (`daily_<период>.pkl`),
  не меньше 5 суток с рынком к воне. Нет рынка к воне — отдельно, в отчёте.
- **Входы и доходы журналов** — их собственные выходы 10 / 25 / 48 ч из файлов бэктестов:

  | Журнал | Источник | Периоды |
  |---|---|---|
  | ⏰ | s88: open9, r1 ≥ 5%, доля ≥ 20% | три |
  | 🔝 | s65 | 2022–2024, 2024–2026 |
  | 👀 | s83 | 2024–2026 |
  | 🇰🇷 | s118 (2020–2024), s20 (2024–2026) | три |

- **Событие** — kshare7 ≥ 20%. **Контроль** — < 20%.
- **Порог** (двусторонний):
  1. Δ одного знака на всех доступных периодах журнала, вместе |t| ≥ 2.
  2. Знак задаёт двойника: Δ > 0 — «только при доле Кореи ≥ 20%», Δ < 0 — «только при < 20%».
  3. Правило владельца для выбранной части на 2024–2026 гг. (частота двойнику не нужна).
- **Разрез** — доза: < 10 / 10–20 / 20–35 / ≥ 35%.
