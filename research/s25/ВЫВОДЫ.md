# s25 — новые источники данных: что есть, что даёт, как достать (12.11.2026)

Задача владельца: найти новые инструменты получения данных и понять, какие данные могут быть очень полезны.

Что уже известно из s2–s24:
- сильные эффекты дают **шоки предложения и внимания** (листинги на розничных площадках, делистинги, ярлыки Binance) и
  **вынужденные потоки** (займ и отдача маржи, фандинг);
- потоки тейкеров, OI и соотношения лонг/шорт слабы.

Поэтому ценнее всего данные о событиях, после которых кто-то вынужден покупать или продавать.

Проверка доступа: мои запросы из облака (американский IP) плюс веб-поиск трёх помощников.

Метки:
- [L] — вызвано вживую;
- [D] — по документации;
- [U] — не проверено.

Часть сервисов (Bybit, Binance fapi, лента Upbit) блокирует облако — с сервера бота они, скорее всего, откроются.

## Подробнее по группам

### Корейские биржи
- **Upbit:**
  - лента уведомлений `api-manager.upbit.com` закрыта Cloudflare для облака, старый `/api/v1/notices` — 404;
  - есть официальный Telegram `upbit_news` (с 05.2025) и WebSocket уведомлений (с 31.08.2026, нужен ключ Upbit, только
    вживую);
  - до лета 2025 бесплатных уведомлений не нашлось.
- **Bithumb:** официальный `GET https://api.bithumb.com/v1/notices?count=20` (последние 20) и
  `/v1/market/virtual_asset_warning` (текущие предупреждения с шагом и датой окончания). История — неофициальное
  Telegram-зеркало `bithumb_notice` с 01.2022 (в 2026-05-03 дубли).
- **Флаги Upbit** (`market_warning`, `caution`) бот пишет с 10.11 (`upbit_flags.csv`).

### Листинги и делистинги других бирж
- **KuCoin** — `GET https://api.kucoin.com/api/v3/announcements?annType=new-listings|delistings&startTime=…` (мс), полная
  история.
- **OKX** — `/api/v5/support/announcements`, ответ зависит от IP: из США — только OKX-US. С сервера проверить; запасной
  вариант — Telegram `OKXAnnouncements`.
- **Bybit** — `/v5/announcements/index` (из облака закрыт).
- **Bitget** — только 30 дней.
- **Gate и MEXC** — API нет. У Gate есть `buy_start` по текущим парам; у MEXC — неофициальный Telegram до 11.2025.
- **Telegram-каналы бирж** читаются через `https://t.me/s/<канал>?before=<id>` — по 20 постов, до самого первого, без
  аккаунта.

### Предложение монеты (замена данным о разлоках)
- **Santiment** — `api.santiment.net/graphql`, без ключа: `marketcap_usd`, `price_usd`, `total_supply` за всю историю,
  1000 запросов в месяц. Отношение капитализации к цене — предложение в обращении по дням: скачок = разлок или эмиссия.
- **CoinGecko** — без ключа 365 суток; Basic ($29 в мес.) — 2 года.
- **CoinGecko `supply_breakdown`** (план Analyst) — адреса некрупных кошельков команды и казначейства, текущий снимок.

### Ликвидации
- **У Binance USDT-M бесплатного архива ликвидаций нет.** На data.binance.vision — только COIN-M до 10.2024; поток
  `!forceOrder@arr` прореженный (одна ликвидация в секунду по монете).
- **Bybit** отдаёт все ликвидации в WebSocket `allLiquidation` — только вживую.
- **Gate** — каждая ликвидация примерно за год (`/futures/usdt/liq_orders`, окна по часу) и 5-мин статистика за 180 суток.
- **Coinalyze** — сводные ряды по площадкам, бесплатный ключ.
- **CoinGlass** — от $420 в год.

### Hyperliquid
- **API без ключа:**
  - свечи (дневные — полностью, часовые — около 7 месяцев);
  - фандинг с листинга;
  - текущие OI и премия;
  - `predictedFundings` — прогноз фандинга Hyperliquid, Binance и Bybit рядом.
- **Позиции любого счёта** — полные; история сделок — только последние 10 тыс.
- **Полная история сделок** со всеми ликвидациями и адресами — в S3 (`hl-mainnet-node-data`, с 03.2025). Нужен
  аккаунт AWS и оплата трафика.

### Внимание
- **X `tweets/counts/all`** — лучший вариант: полная история, почасово или по дням, кэштеги.
- **Остальное хуже:**
  - Santiment social — бесплатно только год с отставанием 30 суток, 2 года — $249 в мес.;
  - LunarCrush — от $90 в мес.;
  - Kaito API нет;
  - бесплатный API CryptoPanic закрыт;
  - у Binance Square нет API для чтения;
  - Google Trends — только по заявке;
  - Wikipedia — только крупные монеты.
- **Binance Web3:** рейтинг «социального хайпа» и сигналы «умных денег» — снимки, только записывать.

## Что бот может начать записывать сам (истории нет нигде)

1. **Уведомления и предупреждения Bithumb** (официальный API) и **Upbit** (Telegram `upbit_news` без аккаунта) — с
   точным временем.
2. **Ликвидации** Binance (прореженные) и Bybit (полные) через WebSocket. Это отдельный процесс, нагрузка на сеть
   умеренная.
3. **Позиции 100–200 лучших счетов Hyperliquid** раз в час (вес ~4000 в час при пределе 1200 в минуту).
4. **Позиции топ-портфелей копитрейдинга Binance** раз в сутки.
5. **Объявления Bybit и OKX** (с сервера).

## С чего начать

- **Сразу, бесплатно, история уже есть:**
  - корейские предупреждения, делистинги и остановки ввода-вывода по уведомлениям Upbit и Bithumb → цена фьючерса Binance;
  - календарь листингов и делистингов KuCoin, OKX, Bybit, Coinbase;
  - скачки предложения по Santiment;
  - приток монеты на кошельки Binance по DefiLlama.
- **Решение владельца:**
  - бесплатный ключ Coinalyze — ликвидации за 2+ года;
  - X API (~$130 разово) — счётчики упоминаний монет;
  - при успехе замены разлоков — месяц CoinGlass Startup (~$95) или Tokenomist.
- **Запись на сервере — только по «да» владельца:** уведомления Bithumb и Upbit, ликвидации Bybit, позиции лучших счетов
  Hyperliquid.
