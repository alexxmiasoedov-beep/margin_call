# s239 — метод 🗳 на часовой сетке (20.11.2026)

Владелец: «продолжай искать новые стратегии». 🗳 (s225) — комитет из 100 правил на признаках «необычно для монеты»,
сетка 4 ч; эффект есть только в момент займа (пост канала не старше 30 мин, s228). На сетке 4 ч бот видит лишь каждый
четвёртый такой момент. В s224a часовая сетка проверялась на абсолютных признаках s223 и размыла сигнал. С признаками
s225 её не проверяли.

## Метод (записан 20.11 до расчёта)

- **Наблюдения** — `s224h_feat.pkl`: монета канала в каждый час (260 тыс. наблюдений, 37 признаков).
- **Признаки** — к ним 12 признаков «необычно для монеты» тем же `s225/features.py` (IN = `s224h_feat.pkl`,
  OUT = `s225h_feat.pkl`).
- **Исход** — шорт 4 ч с хеджем индексом альтов (`y_hs4`, стоп 10%).
- **Перебор и комитет** — как в s225, без изменений:
  - `s216/bombe.py` с PFX = s225h: квинтили на A, ≥ 150 наблюдений на A, 2000 лучших → отсев на B, три перемешанных
    контроля;
  - `s223/committee.py`: 100 лучших по B, k из {1, 3, 10, 30} выбран на B.
- **Порог на C** — как в s225: t ≥ 3 по неделям, ≥ 20 сделок в месяц, обе половины C в плюсе, лучше плацебо, лучше
  контроля.
- **Порог на D** (22.10–19.11, часовые строки `s224/feat_D_s225.pkl`, `s224/d_check.py` с сеткой 1 ч) — как в s224:
  D > 0, C + D t ≥ 3, ≥ 20 сделок в месяц, лучше плацебо.
- **Сравнение с 🗳 (сетка 4 ч):** C + D +0,33% (t 3,2), около 390 сделок в месяц. Часовой комитет предлагается
  владельцу двойником 🗳, только если прошёл оба порога и на C + D у него больше сделок при доходе на сделку не ниже
  +0,25%.

## Результат (20.11) — порог на C не пройден, D не проверяется

Признаки — `s225h_feat.pkl` (260 286 × 59). Логи — `s239_features.log`, `s239_bombe.log`, `s239_committee.log`
в папке данных.

- **Перебор.** Наблюдений A / B / C — 88 тыс. / 113 тыс. / 59 тыс.; 171 тыс. правил. Отсев на B прошли 799 правил,
  на C у них в среднем +0,17% при контроле −0,09 / −0,03 / +0,07%.
- **Комитет** (k = 3 выбран на B: 3183 сделки, +0,33%, t 3,7) на C:
  - 2313 сделок, 347 в месяц;
  - доход **+0,01%** (t 0,1), половины +0,10 / −0,13%;
  - сверх плацебо +0,14% (t 1,3); контроль −0,04 / −0,02 / −0,03%.
- **На сетке 4 ч** тот же метод на C даёт +0,33% (t 3,1).

**Вывод.**
- Часовые входы размывают сигнал 🗳, как и в s224a: соседние часы одной монеты почти одинаковы, а отбор на A и B
  подстраивается под шум.
- 🗳 остаётся на сетке 4 ч. Двойника нет.
- Для понимания: на сетке 4 ч доход 🗳 по часу входа неровный (s225: 00, 12 и 20 UTC — +0,55…+0,85%; 08 и 16 UTC —
  −0,23 и −0,10%). Часть эффекта может быть связана со временем суток. Это проверять только вживую, отбирать по часу
  нельзя — подгонка.
