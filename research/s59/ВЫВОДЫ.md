# s59 — делистинг монеты на других биржах (Bybit, KuCoin) при живом фьючерсе Binance: отброшено по частоте (16.11.2026)

- **Идея.** Расширить 📢 (шорт после делистинга на Binance, +9% на сделку, 6–7 в месяц) делистингами на других крупных
  биржах.
- **Данные:**
  - Bybit — канал `t.me/s/Bybit_Announcements` без аккаунта (`bybit_scrape.py`, 5059 постов с 09.2024);
  - KuCoin — `s31/ku_ann.json`;
  - у OKX публичный API отдаёт только последние объявления.
- **Частота:** с 10.2024 у монет с фьючерсом Binance — 41 событие (1,7 в месяц): Bybit 32, KuCoin 9. Это намного меньше
  20 в месяц, поэтому доходы не считались.
