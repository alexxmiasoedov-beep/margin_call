# s38 — опись данных: всё, что отдаёт Binance, и что есть у BingX и Gate сверх него (16.11.2026)

Задача владельца: посмотреть, какие данные вообще можно достать с Binance, затем проверить другую биржу (BingX) — нет ли
там полезных параметров, которых нет на Binance. Проверено из облака без ключей (`probe.py` повторяет все запросы).
Из облака Binance открывается через `www.binance.com` (`fapi.binance.com` и `api.binance.com` отвечают 451), с сервера
бота — напрямую.

## Итог

- **Binance отдаёт почти всё бесплатно, но история с позициями толпы короткая.**
  - Архив data.binance.vision: свечи, сделки, стакан с 2023 г., 5-мин метрики с 2020 г., премия, фандинг.
  - API: соотношения лонг/шорт, OI, базис — только за 30 сут.
  - Бесплатной истории ликвидаций USDT-M нет.
- **Пять источников Binance, которые мы ещё не брали.** Все отдают только текущее состояние — их надо записывать:
  1. справочник монет с отраслевыми тегами и пометками Monitoring / Seed;
  2. страховой фонд по группам контрактов;
  3. OI вместе с монетами в обращении по CMC;
  4. состав индекса по биржам;
  5. P2P-курсы USDT к местным валютам.
- **BingX ничего существенного сверх Binance не даёт.** Тот же набор, история короче. Позиций толпы, истории OI и
  ликвидаций в открытом API нет. Полезен только календарь своих листингов. 23% монет он листит раньше Binance — в среднем
  на 6 сут, для сигнала мало.
- **Нужное нашлось у Gate.** Почасовые ликвидации лонгов и шортов, число счетов в лонге и в шорте, позиции крупных счетов —
  за 180 сут без ключа. Gate уже использовался в `research/futures` как признак для стопов, но отдельным сигналом для
  журналов не проверялся.

## Binance — только с ключом или только записью

- **С ключом бота:**
  - история ставки займа по монете;
  - доступный пул займа (бот пишет с 10.11.2026);
  - данные кросс- и изолированной маржи.
- **WebSocket, истории нет — только записывать:**
  - ликвидации `forceOrder` (не больше одной в секунду на символ);
  - потоки марк-цены, лучших цен, стакана.

## BingX — публичное API (`open-api.bingx.com`, из облака открывается)

| Что | Есть | История |
|---|---|---|
| контракты: 1339 (1290 к USDT), **время запуска `launchTime`** и снятия, статус | да | с 2020 г., включая снятые |
| свечи, свечи марк-цены | да | примерно с 2024 г. |
| фандинг: ставка, интервал, **предел ставки ±2%** | да | не меньше 200 сут |
| текущий OI, стакан, последние сделки, тикеры | да | — |
| история OI, соотношения лонг/шорт, история сделок | нет в открытом API (сделки — с ключом) | — |

- **Чего нет на Binance:**
  - 146 контрактов. Часть из них — другие названия (OPENLEDGER = OPEN, MONAD = MON), часть — монеты без фьючерса Binance
    (CRO, OKB, MNT, PI и др.), остальное — синтетические валютные пары.
  - Свой календарь листингов.
- **Опережение Binance.** Из 270 монет, запущенных на фьючерсах Binance после 10.2024 и торгующихся на BingX:
  - в тот же день — 54%;
  - BingX раньше — 23%, медиана опережения 5,9 сут;
  - BingX позже — 23%.
- **Вывод.** Для анализа BingX почти ничего не добавляет: его OI и фандинг повторяют Binance, позиций толпы нет. Календарь
  листингов можно проверить тем же правилом, что KuCoin (s31), но ждать от него стоит не больше, чем от KuCoin.

## Gate — параметры, которых нет на Binance (`api.gateio.ws`, без ключа)

`futures/usdt/contract_stats` — по каждому контракту, интервал от 5 мин до суток, **история 180 сут**:
- **ликвидации лонгов и шортов** — количество, размер, сумма в $. У Binance бесплатной истории нет;
- **число счетов в лонге и в шорте** (`long_users`, `short_users`). У Binance только соотношение;
- позиции крупных счетов (число и размер в лонге и шорте), объёмы тейкеров, OI, фандинг.

Использовалось в `research/futures` как признак для стопов сигналов канала. Как самостоятельный сигнал не проверялось.

## Новые виды показателей на других биржах (уточнение владельца)

Владельцу нужны не более длинные ряды тех же данных, а показатели, которых у Binance нет совсем. Свои займы маржи Binance
публикует: ставки и пул, а через канал MarginData — объёмы займов. На них построен бот. Ниже — то, чего у Binance нет;
всё проверено из облака без ключа.

|---|---|---|---|---|
| **OKX** | займы маржи: занято под лонг к занятому под шорт (`rubik/stat/margin/loan-ratio`) | нет | 180 сут, сутки; ~55% монет | вторая маржинальная толпа, спрос на займ под шорт |
| OKX | put/call по объёму и OI опционов | нет | 72 сут | для BTC, ETH и ещё нескольких монет |

| **Gate** | ликвидации лонгов и шортов по часам | нет (поток без истории) | 180 сут | каскады ликвидаций по монете |

записывать.

## Что предлагается

1. **Проверить на 180 сутках Gate две гипотезы** (исследование, бот не меняется):
   - каскад ликвидаций лонгов по монете → отскок;
   - крайнее число счетов в лонге → разворот.
   Важно: это ликвидации и счета только Gate, рынок целиком они показывают косвенно.
2. **Записывать на сервере то, у чего нет истории.** Это изменение бота — только по «да» владельца:
   - раз в сутки — справочник монет Binance (история пометок Monitoring и Seed, теги);
   - раз в сутки — страховой фонд и OI с монетами в обращении по CMC;
   - раз в час — `contract_stats` Gate, чтобы история не ограничивалась 180 сутками.
3. **BingX дальше не разбирать.** Платные источники из s25 (Coinalyze, CoinGlass) по-прежнему дают больше.
