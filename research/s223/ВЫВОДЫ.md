# s223 — сочетания займов на доходе с хеджем рынка альтов и «комитет» правил (20.11.2026)

Владелец (20.11): «не ищи другие источники, ищи сочетания среди этого — сочетаниях займов с объёмом самих займов,
скоростью набора, отдачи, стоимости, время удержания, и так же сочетание с ОИ, фандингом, изменением цены, лимитами,
объёмами, соотношением лонг/шорт».

## Почему ещё раз и что нового

В s216 тот же перебор (37 признаков, ~104 тыс. правил, отрезки A / B / C) находки не дал. Но там же видно:
- правила отбирают монеты, которые за неделю отстают от среднего по каналу на ~1,4 п. п.;
- на C 86% из 1042 правил лучше среднего, но шорт по ним в нуле: в C альты росли;
- доход всех наблюдений шорта 7 сут по отрезкам: −0,38 / +2,19 / −1,27%. Общий ход рынка больше разницы, которую дают
  правила, и меняет знак между отрезками.

Отсюда два отличия от s216:
1. **Доход с хеджем индексом альтов** (s103: равный вес, фьючерсы с оборотом ≥ 5 млн $, без BTC) на фактический срок
   сделки: шорт — `net + ход индекса`, лонг — `net − ход индекса`. Отбор идёт по отставанию или опережению рынка,
   а не по его направлению. В боте так можно торговать парой «шорт монеты + лонг корзины альтов»; у 🏦 уже есть второй
   баланс с хеджем BTC.
2. **Комитет правил.** Вместо одного лучшего правила сигнал даёт голосование многих правил, отобранных на A и B.
   В s218 у прошедших отсев правил на C в среднем было +1,07% (24 ч) и +1,36% (48 ч) при контроле около нуля, а лучшее
   отдельное правило не держалось. Сведения в правилах есть, но разбросаны по многим.

## Метод (записан 20.11 до расчёта)

Всё как в s216 (`s216/ВЫВОДЫ.md`, «Метод»):
- наблюдения — монета канала на сетке 4 ч;
- те же 37 признаков и условия;
- одиночные правила, пары, продолжения лучших пар;
- отрезки A 20.02–30.09.2025, B 01.10.2025–31.03.2026, C 01.04–21.10.2026;
- отсев на B: среднее > 0, выше всех наблюдений B, n ≥ 30;
- контроль: 3 прогона с исходами, перемешанными внутри месяца.

Меняются только исходы — 8 исходов с хеджем: шорт и лонг на 4 ч (стоп 10%), 24 ч (стоп 25%), 48 ч (стоп 25%), 7 сут
(стоп 50%).

**Комитет** — для каждого исхода; всё выбирается на A и B, C не виден:
- 100 лучших по t на B правил из прошедших отсев (если прошло меньше — все);
- голос наблюдения — сколько из них выполнено;
- порог голосов k — из {1, 3, 10, 30} по наибольшему t честных сделок на B;
- честные сделки: вход на закрытии T, одна сделка на монету до выхода, доход с хеджем, t по неделям.

**Порог находки — все пункты на C** (комитет с k, выбранным на B):
1. Средний доход с хеджем > 0 при t ≥ 3 по неделям.
2. ≥ 20 сделок в месяц.
3. Обе половины C в плюсе (граница — 11.07.2026).
4. Лучше плацебо той же монеты (±45/90/135 сут, тоже с хеджем).
5. Лучше комитетов, построенных так же на перемешанных исходах (среднее трёх прогонов).

Если порог пройден — до предложения владельцу ещё одна проверка на свежих данных после 21.10.2026 (отрезок D). Её
условия запишу до расчёта. Если не пройден — журнала нет.

Для отчёта — как в s216: прошедшие B на C в среднем, лучшее по B правило на C, сводки по признакам.
