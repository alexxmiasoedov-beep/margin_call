# s165 — розничный памп (спот или Корея) + истощение покупок + без перегруженных шортов (18.11.2026)

Расширение s164 для частоты. Механизм тот же: памп делает розница (спот Binance или корейские биржи), а не вынос шортов.
Покупки на свече пампа иссякли. Шорты не перегружены.

## Гипотеза (записана 18.11 до расчёта)

**Пампы** — s154b (+15% за ≤ 2 ч из покоя, шорт 10/25/48).

**Отбор** — все три условия:
- доля спота Binance ≥ 26% **или** доля Upbit + Bithumb ≥ 20% в обороте часа пампа (колонка `kr`: s49 для 2024–2026 гг.,
  s119 для 2022–2024 гг.; для 2020–2022 гг. корейских данных нет — только спот);
- расхождение цены и дельты (F4);
- ставка последнего начисления > −0,1% за 8 ч.

**Порог:**
- в плюсе в каждом периоде, вместе t ≥ 3;
- в 2024–2026 гг. — правило владельца.
