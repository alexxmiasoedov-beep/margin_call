# s232 — «послужной список» вкладчика для 🐋 (20.11.2026)

Владелец: «продолжай поиск» (подход «Cicada»: идти по цепочке ключей). Завод 🐋 — это сметание токенов с адреса
пополнения Binance (s200). Адрес пополнения в сети Ethereum у клиента Binance один для всех токенов. Значит, адрес —
это конкретный клиент. Следующий ключ — его история: падала ли цена после его прошлых заводов. Если одни клиенты
продают «со знанием» (команды, фонды), а другие — по расписанию (маркетмейкеры, OTC), послужной список их разделит.

## Метод (записан 20.11 до расчёта)

- **События** — входы 🐋 по правилу бота на трёх периодах (`s182_g2_<период>.pkl`, s182 Г2), всего 1882 сделки:
  2020–2022 — 424, 2022–2024 — 494, 2024–2026 — 964. Исход — шорт 24 ч, стоп +25%, с хеджем индексом альтов (`hed`),
  плацебо — та же монета за 45/90/135 сут (`pl`).
- **Клиент** — адрес пополнения `frm` (`s182_origin.pkl`).
- **Послужной список** — средний `hed` прошлых сделок того же адреса, закрытых до входа (вход прошлой сделки + 24 ч ≤ вход
  текущей); сделки всех монет и всех периодов до текущей.
- **Группы:**
  - N — у адреса нет закрытых прошлых сделок;
  - P — список > 0;
  - M — список ≤ 0.
- **Основная гипотеза** — P лучше M: разность средних `hed` > 0 в каждом из трёх периодов, по трём периодам вместе
  t ≥ 2 (t по неделям).
- **Для отчёта:** P и M против N; опыт адреса (≥ 10 прошлых сделок — похоже на маркетмейкера — против 1–9); доля
  сделок, у которых список есть.
- **Если гипотеза пройдена** — двойник 🐋 «только клиенты с положительным списком» предлагается владельцу, если
  у группы P на 2024–2026 гг. доход > 0 и t ≥ 2. Иначе — только запись.
