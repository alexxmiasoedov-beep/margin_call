## Г1 — «займ пошёл»: ставка займа Binance уходит с пола при фандинге ≥ 0 → шорт 7 сут

- **Данные.** Часовая ставка займа маржи Binance (публичный `bapi … history-interest-rate`):
  - с 09.2024 — `s11/rates`;
  - 01.2023–09.2024 — докачивается для всех активов маржи с перпом (`rates_fetch.py`, `/home/user/mc_data/s190/rates`).

  До 20.02.2023 ставка ручная — периода 2020–2022 гг. для этой гипотезы нет.
- **Событие:**
  - x = ставка / пол, где пол — 10-й перцентиль часовой ставки за прошлые 30 сут;
  - вход: x ≥ 1,5 впервые после ≥ 7 сут с x < 1,2 и сумма фандинга за 7 сут ≥ 0;
  - фьючерс старше 30 сут; одна сделка на монету за 7 сут;
  - шорт с закрытия ближайшей 15-мин свечи после часа ставки на 7 сут, стоп +50%.
- **Контроль (а)** — то же событие при фандинге за 7 сут ≤ −0,3% (арбитражный займ).
- **Подпериоды:** 03.2023–09.2024 / 10.2024–09.2025 / 10.2025–10.2026.
- **Порог:**
  1. Событие в плюсе в каждом подпериоде.
  2. Δ (событие − контроль (а)) > 0 в каждом подпериоде (где у контроля < 10 событий — только знак события), вместе t ≥ 3.
  3. Правило владельца для событий на 10.2024–10.2026: ≥ 20 в месяц, обе половины в плюсе, t ≥ 3, лучше плацебо.
- **Разрезы:** с хеджем; вход журнала по монете в ±7 сут — есть / нет; x ≥ 3 вместо 1,5.
- **Уточнение 19.11.2026 до расчёта доходов.** На часовом ряду условие «7 сут подряд x < 1,2» почти не выполняется:
  часовая ставка часто на час выходит выше 1,2 пола. За 10.2024–10.2026 вышло 46 событий (≈ 1,9 в месяц), а на суточном
  ряду для тех же активов — 650. Оценка частоты в изучении s188 была по суточному ряду.
  - **Основной вариант — суточный ряд:** ставка на конец суток UTC (последняя часовая), пол — 10-й перцентиль за 30 сут,
    x ≥ 1,5 впервые после 7 сут с x < 1,2. Вход — закрытие свечи 00:00–00:15 следующих суток.
  - Часовой вариант — для отчёта: по частоте он правило владельца не проходит.
  - Доходы ни одного из вариантов до этого уточнения не считались.

## Г2 — «конец суток ботов пробоя Upbit»: шорт 23:45 → 00:15 UTC

- **Механизм.** Корейский учебный бот (pyupbit-autotrade, Ларри Уильямс): на сутках Upbit (с 00:00 UTC) покупает при
  касании цели Oₜ + 0,5·(Hₜ₋₁ − Lₜ₋₁) и продаёт всё по рынку в 23:59:50 UTC.
- **Событие:**
  - 23:45 UTC; у монеты есть рынок к воне на Upbit (оборот Upbit за сутки > 0 в дневной панели s183);
  - максимум суток с 00:00 UTC выше цели Oₜ + 0,5·(Hₜ₋₁ − Lₜ₋₁) по 15-мин свечам перпа;
  - доля Upbit + Bithumb в обороте суток ≥ 20% (дневная панель s183: оборот к воне / (Корея + перп + спот Binance));
  - фьючерс старше суток.

  Шорт с закрытия свечи 23:30–23:45 до закрытия свечи 00:00–00:15 (30 мин), комиссия 0,1%.
- **Контроль (а)** — монеты с рынком к воне и долей Кореи ≥ 20% без пробоя в те же сутки, тот же интервал.
- **Порог:**
  1. Δ (событие − контроль (а)) одного знака на трёх периодах, вместе t ≥ 3.
  2. После комиссии событие в плюсе на всех периодах.
  3. Правило владельца на 2024–2026 гг.
- **Разрезы:**
  - (б) те же события на 30 мин раньше (23:00 → 23:30) — продажи ботов ещё нет;
  - выходные отдельно;
  - доза — сила пробоя Hₜ / цель − 1: < 2% / 2–5% / ≥ 5%;
  - валовой ход без комиссии (для понимания размера эффекта).
