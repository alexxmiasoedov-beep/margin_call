с размером разлока к суточному обороту перпа: закон квадратного корня. В s196 медиана λ у событий 🔑⁺ — 0,52, у
отвергнутого анбондинга — 0,04. Дозу внутри 🔑⁺ по обороту не проверяли. По доле обращения её проверяли: U1 ≥ 5% —

## Правило

- **События и сделки** — 🔑⁺ из s142 по трём периодам (`/home/user/mc_data/s142_<период>.pkl`):
  - разовый разлок ≥ 1% обращения по DefiLlama, кроме казны;
  - шорт с T − 7 сут до T + 1 сут, стоп +50%.
- **λ = N · P / V̄:**
  - N — число токенов разлока в сутках проекта (`s139/unlock_test.events()`, сумма по сделке s142);
  - P — цена перпа на входе, с поправкой на множитель в тикере;
  - V̄ — средний суточный оборот перпа в USDT за 7 сут до входа.
- **Основной вариант — λ ≥ 0,5.** Для отчёта — λ ≥ 0,25, λ ≥ 1, λ < 0,5.
- **t** — с кластерами по неделям: сделки длятся 8 сут и перекрываются (s212). Для отчёта — ещё и по месяцам.

## Порог

1. **2024–2026 гг. для λ ≥ 0,5:**
   - ≥ 20 сделок в месяц;
