# s196 — изучение: предложение с известной датой выхода вне разлоков — анбондинг стейкинга, концы ve-блокировок, cooldown

19.11.2026. Этап изучения в духе «Cicada 3301»: второй класс расписанного предложения рядом с разлоками 🔑⁺ и заводами 🐋 —
держатель сам запускает выход, и дата, когда монеты станут ликвидными, записана в сети (анбондинг PoS, конец ve-блокировки,
cooldown, ScheduledUnstake). Полный отчёт — `reports/изучение.md`; пробы (только охват, частоты, размеры и поведение
держателей, без доходов) — `study/`, кэш — `/home/user/mc_data/s196/` (≈ 0,2 ГБ).

## Главное

1. **Класс частый по числу событий:** «один держатель ≥ 0,1% обращения» по всем источникам с историей без ключа —
   60 / 44 / 47 в месяц по трём периодам, «≥ 0,5%» — 9,4 / 8,9 / 8,0 (без AVAX); снимок «сейчас» 17 сетей Cosmos с перпом —
   31 и 9 в месяц.
2. **Ключ «запись очереди живёт весь срок»:** один снимок `unbonding_delegations` на архивной высоте даёт все анбондинги
   за 21 сут с точной датой завершения. Архивы без ключа: ATOM (с 02.2022), TIA (с 10.2023), KAVA (с 05.2022) —
   из chain-registry; Polkadot/Kusama — Statescan (Staking.Unbonded 2020–2025); EGLD, ROSE, XTZ, APT, AVAX — открытые API;
   ve, cooldown, ScheduledUnstake — логи Ethereum. Остальные сети Cosmos — только «сейчас» (запись вперёд).
3. **Но выходы на порядок меньше разлоков:** анбондинг ≥ 0,1% обращения — медиана 0,04 суточного оборота перпа,
   событие 🔑⁺ — 0,52. По силе давления (≥ 0,25 суточного оборота) — 1,5 / 2,6 / 3,3 события в месяц.
4. **Выход ≠ продажа:** TIA — 54% крупных держателей не двигали монеты 30 сут после завершения, на биржу по мемо ушло 1,8%
   объёма; ERC-20 — 1% крупных выходов кончается переводом на биржу за 14 сут; ve без продления — вывели и не перезамкнули
   CRV 54%, PENDLE 46%, FXS 34%; ICP — 7,6% обращения «Dissolved» и не выведено.
5. **Анбондинг ↔ разлок:** перед разлоком TIA 30.10.2024 очередь выросла с 1,2% до 5,4% обращения (завершения 26–30.10).
6. **Ключи закрываются:** Polkadot — анбондинг номинаторов ≈ 2 сут (реф. 1910, 07.2026), стейкинг DOT/KSM на Asset Hub;
   Celestia — 14 сут (CIP-37); stkAAVE — cooldown 2 сут. (Поправка: у Aptos с 2025 г. событие `UnlockStake` — история
   полная, 04.2023–11.2026.)
7. **Эмпирики «анбондинг альта → цена» нет ни в одной стране;** аналоги — локапы IPO (Field–Hanka: −1,5% за 3 дня),
   限售股解禁 и 보호예수 해제 (давление до даты).

## Гипотезы (частоты — в месяц, 10.2020–09.2022 / 10.2022–09.2024 / 10.2024–10.2026, источники с историей без ключа)

| № | Гипотеза | Событий в месяц | Контроль |
|---|---|---|---|
| Г1 | «Держатель сам открыл выход»: анбондинг PoS одного держателя ≥ 0,5% обращения → шорт T − 7 → T + 1 | ≥ 0,5%: 3,4 / 4,7 / 4,9; ≥ 0,1%: 38,6 / 27,2 / 30,1 | делегирование той же величины → лонг; плацебо |
| Г2 | «Конец расписанного выхода в DeFi»: ve без продления, Cooldown stkAAVE, ScheduledUnstake API3, GRT/LPT L1 ≥ 0,5% → шорт T − 7 → T + 1 | ≥ 0,5%: 6,0 / 4,2 / 3,1; ≥ 0,1%: 21,5 / 16,4 / 17,1 | новые блокировки той же величины; концы «перекладчиков» |
| Г3 | «Анбондинг перед разлоком»: у 🔑⁺ монеты со стейкингом очередь с завершением у T ≥ 25% разлока → двойник 🔑⁺ | 0,6 / 3,0 / 6,3 события 🔑⁺ на таких монетах; с историей очереди — единицы | 🔑⁺ без роста очереди |

Ожидания скромные: по размеру к рынку выход ≈ 0,1 разлока 🔑⁺; правило владельца по частоте (≥ 20 в месяц) проходит только
порог ≥ 0,1% обращения, где давление — сотые доли суточного оборота. Г3 проверяется только записью вперёд (суточный снимок
очереди ≈ 10 сетей — по «да» владельца).

## Не подходит

Polkadot после 07.2026 и Kusama (2 / 7 сут), SOL, SUI, NEAR, TRX, XTZ (1–5 сут или нет истории без ключа), AVAX (конец
срочной ставки, дата выбрана при входе; 62–68% — перезапуск того же узла), ICP (генезисные нейроны = график разлока,
истории нет), Stacks (≤ 2 события в месяц), Hive/Steem (выплаты по 0,01% обращения), промо Binance Locked Staking (объём
пула не публикуется), veSTG/veBAL/veAERO/veCAKE.
