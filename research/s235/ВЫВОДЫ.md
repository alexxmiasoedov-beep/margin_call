# s235 — вето «BTC упал за сутки» для журналов шорта пампов (20.11.2026)

Продолжение s234, вопрос владельца о минусовых сделках. Вживую шорты, открытые после падения BTC за сутки на ≥ 2%, дали
−0,85% на сделку и 22% стопов против +3,00% и 12% у остальных. На всех пампах s159 знак тот же во всех трёх периодах,
но эти данные уже просмотрены в s234 — здесь они не в счёт.

## Метод (записан 20.11 до расчёта)

- **Вето:** ход BTC за 24 ч до входа ≤ −2% (закрытие 15-мин свечи входа к закрытию за сутки до неё, архив свечей
  периода).
- **Проверка — на бэктестах самих журналов, которые в s234 не смотрели:**

| Журнал | Данные | Исход |
|---|---|---|
| 🛒 | `s49/trades.pkl`, доля спота ≥ 26% | шорт 10/25/48 (`net`) |
| пампы с долей Кореи ≥ 20% | `s49/trades.pkl`, `kr` ≥ 0,2 | шорт 10/25/48 |
| 🔝 | `s65/trades.pkl` | шорт 10/25/48 (`S_10_25`) |
| 👀 | `s83/trades.pkl` | шорт 10/25/48 |
| ⏰ | `s88` — три периода: правило бота (час 00–01 UTC, рост ≥ 5%, доля Кореи ≥ 20%) | шорт 10/25/48 |

- **Мера:** разность средних «без вето − под вето», t по неделям.
- **Порог:**
  - разность > 0 у каждого журнала (у ⏰ — в каждом из трёх периодов);
  - по всем журналам вместе t ≥ 2;
  - оставленные сделки не хуже всех сделок журнала.
- **При успехе** — предложить владельцу двойники с вето для журналов, где порог выполнен. В бота — только по «да».
