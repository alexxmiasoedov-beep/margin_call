# s229 — зеркало 🗳: комитет «необычно для монеты» на лонг (20.11.2026)

Владелец: «продолжай поиск». В s225 комитет на признаках «относительно своей истории монеты» проверяли только для шортов;
лонги с хеджем были только в s223 — на абсолютных признаках, все в минусе (от −0,31 до −0,21% на C).

## Гипотеза (записана 20.11 до расчёта)

Зеркало ядра 🗳: толпа счетов уходит в шорт, OI растёт быстрее обычного для монеты, необычная отдача займа — вынужденное
закрытие шортов (сквиз) → через 4–48 ч монета обгоняет рынок альтов. Перебор сам выбирает условия; гипотеза — только
причина, по которой лонг на тех же признаках может работать.

## Метод — как в s225, без изменений

- наблюдения, 49 признаков и исходы — `s225_feat.pkl` (сетка 4 ч, монеты канала, 64 742 наблюдения);
- исходы — 4 лонга с хеджем индексом альтов (лонг − ход индекса): 4 ч (стоп 10%), 24 ч (25%), 48 ч (25%), 7 сут (50%);
- перебор `s216/bombe.py` (PFX=s225): пороги — квинтили на A, ≥ 150 наблюдений на A, 2000 лучших по t на A → отсев
  на B; контроль — три перемешивания исходов внутри месяца;
- комитет `s223/committee.py`: 100 лучших по B, порог голосов k из {1, 3, 10, 30} выбран на B;
- порог на C — как в s225: t ≥ 3 по неделям, ≥ 20 сделок в месяц, обе половины C в плюсе, лучше плацебо и лучше
  контроля из трёх перемешиваний;
- прошедший порог на C — проверка на свежем отрезке D (22.10–19.11.2026) по порогу s224 (D > 0, C + D t ≥ 3,
  ≥ 20 сделок в месяц, лучше плацебо). Не прошёл — журнала нет.

Поправка на множественность: это ещё 4 исхода на тех же данных после 8 исходов s225 и 8 исходов s223 — поэтому
обязательны и контроль, и D.
