# margin_call

Исследование Telegram-канала [MarginData](https://t.me/cryptocode_margin_data)
(бот CryptoCode: объёмы займов и погашений монет на марже) и бот-сканер,
который по найденному правилу шлёт шорт-сигналы в Telegram.

## Правило

**Монета непрерывно присутствует в постах канала ≥ 4 часов (перерывы до
30 минут допустимы) и за последние 4 часа выросла на 8–17 %.**
Горизонт — до суток, направление — шорт.

Проверено на 1.08–2.09.2026: 9 060 постов, 92 210 строк, 302 монеты с
ценами (MEXC / Gate / KuCoin, 15-мин свечи). Доходность считалась сверх
медианы всех альтов, чтобы вычесть движение рынка, по парам «монета·час».

| Рост за 4 ч до поста (при ≥4 ч в канале) | n | Монет | Через 4 ч | Через 24 ч | Убыточных | Ход против позиции |
|---|---|---|---|---|---|---|
| 5–8 % | 262 | 54 | −1,9 % | −7,0 % | 81 % | +11,8 % |
| **8–12 %** | 138 | 36 | −1,8 % | −10,6 % | 89 % | +14,8 % |
| **12–20 %** | 93 | 26 | −5,5 % | −14,1 % | 90 % | +18,8 % |
| > 20 % | 60 | 12 | −7,5 % | −14,9 % | 83 % | +36,2 % |

Зависимость от длительности присутствия в канале (рост > 5 %):
до 1 ч — эффекта нет; 1–3 ч — −3,5 %; **от 4 ч — −8…−9 % за сутки**,
стабильно на всех неделях августа.

Что **не** работает (проверено и отброшено): объём займа BOR в любом виде
(абсолютный, в долларах, относительно обычного для монеты, рост за серию),
отношение B/R, объём погашений REP, колонка CHNG (что это — неясно, 71 %
нулей), лонговые правила (только отскок +1…+2 % на 4 ч после падения > 5 %,
к суткам сдувается в ноль).

Оговорки: один месяц, один режим рынка (BTC +21 % за август); единственная
проигрышная неделя — ралли 8 августа (альты +7,9 % за день). Монеты мелкие,
без учёта комиссий, проскальзывания и ставки займа. Стоп ближе 15–20 % будет
выбиваться часто.

## Бот-сканер

Каждые 15 минут (в режиме GitHub Actions; --loop по умолчанию каждые 5): тянет последние ~5,5 ч постов канала, считает для каждой
монеты длину непрерывной серии, берёт 17 последних 15-мин свечей с биржи
(MEXC → Gate → KuCoin), при попадании в правило шлёт сигнал всем
подписчикам: цена, рост за 4 ч, текущий фандинг бессрочного контракта
(MEXC → Gate → Bitget), время в канале и цифры из поста. Через 4 и 24 часа присылает результат по каждому сигналу
(✅ цена упала / ❌ выросла), чтобы правило проверялось вживую.
Повтор по одной монете — не чаще раза в 24 ч.

Команды бота: `/start` — подписаться, `/status` — монеты, висящие в канале
≥4 ч, с ростом за 4 ч, `/trades` — открытые и закрытые сделки с PnL,
`/pause` и `/resume` — пауза и возобновление торговли, `/stop` — отписаться.

### Исполнитель сделок (BingX)

`bot/trader.py` по каждому сигналу открывает шорт на бессрочном контракте
BingX (кросс-маржа): рыночный вход, стоп-лосс и тейк-профит выставляются
на бирже вместе с ордером, принудительный выход по рынку через `HOLD_H`
часов, не больше `MAX_POSITIONS` позиций, пауза при дневном убытке больше
`DAILY_LOSS_LIMIT_USDT`. Режим `TRADE_MODE`: `paper` — виртуальные сделки
по ценам BingX с журналом и PnL в чате, `live` — реальные ордера. Все входы
и выходы бот присылает в чат. Ключи `BINGX_API_KEY` / `BINGX_API_SECRET`
только через секреты (права: Perpetual Futures Trade, без вывода). На старте
каждого прогона бот проверяет ключи запросом баланса и пишет результат в лог.
Параметры и их смысл — в `.env.example`.

### Запуск

Токен бота — только через переменную окружения, в репозиторий не класть.

Свой сервер:
```bash
cp .env.example .env            # вписать TG_BOT_TOKEN
cd bot && set -a && . ../.env && set +a
python3 scanner.py --loop       # или --once для cron; --dry-run — без отправки
```
Docker:
```bash
docker build -t margin-scanner bot/
docker run -d --restart=always --env-file .env -v scanner-data:/data margin-scanner
```
systemd: `bot/margin-scanner.service` (пути внутри поправить).

GitHub Actions: добавить секрет `TG_BOT_TOKEN` в Settings → Secrets and
variables → Actions — workflow уже в репозитории, состояние (подписчики,
отправленные сигналы) он хранит в `bot/state.json` коммитами. Основной режим —
непрерывная цепочка: прогон работает циклом ~5 ч 40 мин (опрос каждые
5 минут) и в конце сам запускает следующий. Cron каждые 15 минут служит
сторожем: если цепочка оборвалась, он её перезапускает. Цепочка стоит ~24 ч
Actions в сутки — для публичного репозитория бесплатно без ограничений
(для приватного лимит 2 000 мин/мес, тогда оставьте только cron).
